# F06 词典与覆盖方案删除验收

版本：0.26.0；日期：2026-10-26。依据 [F06/F07](F06-F07-提示词生产设计.md) §4、§8、§9 和 [F14](F14-前端设计.md) §6.4，补齐整份特征词典、提示词词典及覆盖方案的本地删除。仅本地开发，不初始化、提交或上传 Git。删除测试仅使用临时测试数据，不清理用户产品库。

## 界面与操作

打开已保存资源后显示“删除整份词典”或“删除覆盖方案”。有未保存草稿时禁用删除，提示先保存或通过原草稿对话框明确放弃。删除对话框显示名称、UUID 和读取修订，说明不可恢复、既有任务与项目保留、词典不能再接收追加。勾选已保存所需内容后，使用现有 HoldButton 按住一秒确认，鼠标/键盘均可；短按、松开、取消、失焦不提交。

实际 DELETE 使用对话框冻结的版本和请求键。未知结果、清理失败以及关闭后重新打开同一资源/版本，保持请求键重试。资源版本变化才生成新键；冲突保留当前编辑内容，需先重新载入核对新版。操作进行中不能关闭对话框或同时修改当前编辑器。

删除成功后刷新列表并清空当前资源编辑器，下一次保存使用新 UUID；词典同时移出当前采样选择/自动回写目标并使当前采样预览失效。覆盖方案与词典页面均有“检查未完成删除”，显式查询尚存内容文件的删除记录；每页显示 20 项，支持手动刷新与分页。重新打开页面后可继续确认清理。读取清单不自动删除文件。

## 后端与持久一致性

新增通用 `prompt_production/deletion.py`，两类资源通过同一产品锁与全部库读写串行。首次删除先验证现有文件结构、版本和请求键，再向 `dictionary_tombstones/<uuid>.json` 或 `coverage_tombstones/<uuid>.json` 原子写入删除记录，随后调用现有 remove_checked，仅移除原 UUID 对应文件且内容摘要必须一致。记录未写入则保持原资源可用；写入后发生持久化/读回故障、无法确认提交结果时，返回 library:delete_unknown 和 outcome:unknown，不声称已拒绝删除或记录一定存在。记录已确认但文件清理失败返回 library:delete_incomplete 和未知结果，重试继续核对清理，不重新写入载荷。

删除记录包含 schema、资源类型、UUID、存储分组、名称、原 revision/version、完整旧文件摘要、历史操作键、删除请求键/摘要与时间；不保留 entries、dimensions、plan、项目字段、端点凭据或模型输出。使用严格模型及额外分组/ID/摘要校验；损坏记录不被当成不存在，损坏原文件不被强删。去重记录不自动过期，两类记录各最多 100000 份，每份历史键最多 4096 个，沿用原请求凭据上限。正常移除后释放原内容分组的 2048 份文件配额。

标记为删除后，GET、导出、更新、旧 POST 创建、导入提交、手动/自动追加均返回410；列表与新采样选择隐藏该资源，旧编号不能复用。历史操作键在删除后仍保留，换新 UUID 重放旧创建键或将其当成删除键会被拒绝。同一删除资源和原版本允许新键再次确认删除，也允许原键重试；原删除键不能用于删除其他资源。清理剩余文件时发现内容摘要变化返回409并保留文件，不提供强制删除开关。

已经创建的任务读取自身冻结词典、规则及结果，源库删除不会取消、重新采样或修改它们。删除与自动追加竞争时共用锁；追加先完成会改变词典版本、使旧版本删除失败，删除先完成则追加明确报 dictionary:deleted。后者将错误保存在任务 append_error，已生成结果和 ready 状态保留，仍可导出或另行追加到其他词典。尚未创建任务的旧采样预览不能绕过已删除输入检查。

| 方法与路径 | 合同 |
|---|---|
| DELETE `/api/prompt-production/dictionaries/{id}` | 无 body，读取版本 If-Match 与 UUID Idempotency-Key；返回原资源摘要及 deleted:true |
| DELETE `/api/prompt-production/coverage-plans/{id}` | 同上，不改变既有任务的冻结计划 |
| GET `/api/prompt-production/dictionaries/deletions` | 尚有原文件的删除记录摘要，limit/cursor 分页 |
| GET `/api/prompt-production/coverage-plans/deletions` | 同上；完成后不再出现在待清理清单 |

接口沿用会话鉴权、Origin、draining、严格查询字段和版本校验，DELETE 拒绝任何请求体。分页游标绑定清单版本，清理改变列表后旧游标返回409。能力增加 library_deletion；OpenAPI 与前端类型同步生成。原 project.db、词典和覆盖计划载荷 schema 不变。

## 当前边界

本轮是单份库资源删除与中断恢复，不提供批量删除、撤销、回收站或自动过期。已冻结的任务和项目中已保存的内容不随库删除擦除；删除记录保留少量元数据，不是全量内容清除操作。Launcher 词库、NSFW 独立模板、真实 Launcher 生成 driver、设置租约、费用门禁、产物登记/恢复和真实 LLM 质量与费用验收仍待后续。
