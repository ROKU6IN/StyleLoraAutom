# 本地图片与标注最小闭环

日期：2026-10-25；包版本 0.2.0，项目 schema 仍为 v1。本轮按用户要求在本地继续实现图片导入、标注编辑、图片＋txt 导出；没有初始化、提交或上传 Git。

## 交付与调用路径

| 操作 | 实现入口 | 数据与文件行为 |
|---|---|---|
| 导入 | exchange.importer.import_images | 扫描稳定排序清单、冻结文件哈希与参数；复制、解码、可信收据、F01 原子登记 |
| 单张编辑 | annotations.editing.edit_manual | 捕获所有标注层读集；CAS 检查后将标签与描述一起写入 manual 层 |
| 批量编辑 | annotations.editing.bulk_edit_manual | 规范化追加/移除集合，验证全部读集后一次事务提交，最多 5,000 张 |
| 审核 | annotations.editing.review_images | 期望状态校验，复用 F01 的原子批量 review 命令 |
| 预览 | exchange.exporter.preview_export | 冻结方案、项目元数据、图片和合并标注，不写导出文件 |
| 导出 | exchange.exporter.export_images | 快照与 I/O 分离，核对字节哈希、成对写入、报告及整目录发布 |

上述入口由 README 中的命令行串联。CLI 不连接网络服务；导出、导入调用期间有项目操作租约，阻止项目被关闭，文件任务在同一项目内串行。F01 单写队列、WAL、schema、原始层写入权限和标注证据边界保持兼容。

## 最小格式和明确边界

- `literal-tags-v1` 是显式首行标签格式；不会将未知词自动认作 Danbooru 标签。首行逗号分隔，空行后的多行文本为自然语言；UTF-8/BOM 和显式 GBK 严格解码，不自动猜编码。支持缺失/空 txt 的不同语义。
- 可选 `catalog-comma-v1` 使用用户提供的词库作别名映射；未知首行部分只在存在显式空行分隔时转入自然语言，否则拒绝歧义。原始解析结果及 reader/parser/encoding/词库哈希保留在标注参数里。
- 标签的显示、编辑和导出沿用 F01 的小写、下划线转空格规则；原始层的原始拼写不改。这里只处理普通字面标签，不执行权重或提示词语法。
- Pillow 完整验证并解码图片；读取真实宽高和 PNG 字符串元数据，拒绝损坏、格式/扩展名不符、超限和多帧文件。原图只复制，不重编码，不计算尚未实现的 F08 pHash。
- manifest 不保存外部素材根目录，只存相对路径和指纹。重复 SHA 跳过；登记前再次检查去重。已缺失的相同图像仍视为重复。重复素材的另一份 txt 不覆盖项目中的标注。
- resume 使用冻结参数；读取时发现图像/txt 被改变、增加或移除则暂停。有效收据可恢复一次，未形成收据的旧本地复制认定中断并标为失败，显式 `--retry-failed` 才开启下一 attempt。不会恢复或调用外部生成服务。
- manual 不覆盖 original；标签/描述一起保存时原子回滚。只改描述不创建标签快照。删除旧标签采用 F01 的证据截止边界，后续新模型结果仍可按规则出现。
- 导出默认 keep，可额外包含 unreviewed；reject、已标记 missing 永不导出。实际原图丢失或哈希改变作为逐图失败，不倒写数据库状态。
- trigger 置于首位且只出现一次；默认未接全量词库，报告明确标注未验证。提供词库时报告仅代表该文件；不把用户的 `complete` 声明当作程序已验证全量覆盖。
- 默认移除该源普通风格标签、显式 blocklist、提供词库的 artist 标签；自然语言命中阻止该图导出，warn 模式允许带告警保留。这是确定性字面匹配，不声称实现完整 F09/F22 语义风格屏蔽。
- UTF-8 txt 无 BOM，LF 换行；默认仅标签，include_nl 时空行后接描述。导出保留原图字节，默认复制模式。硬链接、处理器链和未接入的排序器明确拒绝。

## 导出文件与中断语义

每轮在 `exports/<scheme_id>/.partial-<UTC>-<nonce>/` 内写入，图片/txt/可选 json 先在单图临时目录形成完整文件对，失败清理该组自建文件。全部逐图结果汇总后写 export_report.json 与完成收据，再将整个目录改名为正式版本目录，之前的版本不覆盖。

报告包含方案和选项快照、快照摘要、逐图结果、字节长度/SHA-256、原因码、移除标签、按成功图片计数的词频和 trigger_count，不记录完整描述。正常报告满足 selected = exported + skipped + failed。磁盘满、取消或发布失败不会生成正式目录；临时目录保留 writing/interrupted 收据。磁盘已满时可能无法追加 interrupted 状态，原 writing 状态仍标明未完成。

取消在图片之间检查。当前不自动续写导出或清理中断临时目录；重新导出会新建版本。故障点测试覆盖可控异常窗口，未将其等同于真实断电或所有文件系统的持久性保证。dry-run 不做文件复制，因此不能预先保证之后的磁盘写入一定成功。
