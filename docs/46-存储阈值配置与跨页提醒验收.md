# 存储阈值配置与跨页提醒验收

日期：2026-10-28；版本：0.39.0。仅本地开发，不初始化、提交或上传 Git，不调用真实生成服务。

## 本轮范围

接续 0.38.0 的最近项目和跨项目扫描，实现 05 §3.5 的可配置容量提醒、F11 A009/A010 中的存储阈值配置，以及 F14 全局非模态提醒。本阶段 ProductConfig 仅开放 storage_thresholds；LLM、费用默认值、WD 开关和 MCP 等其它产品设置仍使用已有专用接口或待后续，不伪造统一配置能力。

## 配置与并发

| 接口 | 行为 |
|---|---|
| GET /api/config | revision、version、storage_thresholds、capabilities、limits；首次读取只返回默认值，不创建文件 |
| PATCH /api/config | storage_thresholds 内 project_bytes / total_bytes 至少一个；If-Match 和 Idempotency-Key；返回新配置 |
| GET /api/storage/summary | 只读当前项目与最近一次跨项目历史摘要，用于跨页面提醒；不启动任务或盘点文件 |

默认单项目 20 GiB、扫描范围总量 100 GiB。API 以字节传输，允许 1 MiB–1 PiB 的 MiB 整数倍；页面以整数 MiB 输入，明确 1 GiB=1024 MiB。两个阈值独立，大小严格超过阈值才提醒。布尔值、字符串、浮点数、null、空修改、额外字段与超界值均拒绝。只提供白名单字段，没有路径、环境变量或秘密入口。

持久文件为产品配置目录 `product-config.json`（正常启动在 `%APPDATA%/StyleLoraAutom/`），不进入 `.slproj`；测试可注入隔离目录或内存。文件有 schema_version、递增 revision 与内容摘要，上限 16 KiB。严格验证内容、校验摘要、拒绝链接目录；损坏文件保持原样，不用默认值覆盖。存储配置不可读时扫描与提醒查询报错，不伪装为默认阈值或“未超限”，项目编辑仍可使用。

进程内串行写入，沿用产品单实例边界；版本绑定完整配置与 revision，旧版本以及 A→B→A 的旧版本均冲突。相同值无写入、不增版本、不发事件。原子替换后异常先核对完整内容；无法确认则返回 config:write_unknown/outcome=unknown，前端停止重复保存，要求显式读取已保存值核对。配置不是防同一 Windows 用户篡改的安全边界。

## 扫描与提醒语义

- 当前项目和跨项目扫描都在任务受理时冻结阈值与 config_revision；运行中修改配置不改变本次结果或历史报告。新任务使用新值。原有固定常量已由配置读取替代。
- 当前项目摘要新增 scan_id/config_revision；其 summary 返回 config_changed。项目关闭后释放该句柄的摘要，重开不能把旧句柄结果当作当前扫描。
- 跨项目摘要新增 all_known / selected_known 范围、history_revision、config_revision 和 over_threshold_count；仅对本次冻结范围求和，选定项目不冒称全部项目。
- 新增产品级 GET /api/storage/summary，返回历史 as_of、冻结阈值、部分统计和配置/历史记录变化标记。只读内存摘要与产品配置，不扫描目录，不打开另一数据库，不自动修复或清理。
- 跨项目明细仍最多保留 3 次、15 分钟；另保留最近一次紧凑摘要至下一次完成扫描或退出程序。明细过期标 expired=true，旧时间与字节保留用于提醒，不能冒充新数据；重启后未扫描为 null。
- 取消或失败的扫描不替换已完成提醒。部分统计仍是已读下界；不可访问项目未按零占用计算。逻辑字节不等于磁盘分配量、可回收量或可释放量。
- config.changed/storage.changed 仅发布版本号或扫描编号。浏览器通过事件、回到前台和每 15 秒安全 GET 同步提醒；没有自动 POST、扫描、外部调用或删除。

## 前端

存储页新增“存储提醒设置”，保存前验证 MiB 整数，带读取时的版本和请求键。外部配置更新不覆盖未保存输入；冲突保留草稿。导航受草稿保护；显式“重新载入已保存值（放弃输入）”才能覆盖输入并核对未知结果。读取失败保留草稿、禁用保存，401/离线沿用全局会话限制。

外壳跨页面显示“存储占用提醒”：区分当前项目、当时全部最近项目和选定范围，显示扫描时间、已读大小与当时阈值；配置改变、项目记录改变、部分统计或明细过期均说明需重新扫描。正常且未超限时不出现横幅；没有扫描时不伪造零或“健康”。旧 project_id 的查询结果不会显示为新项目警报。提醒读取失败单独显示不可读取，不继续把旧缓存装作本次成功结果。

截图检查发现提醒会随滚动离开视野，现已置于固定应用顶栏下方，侧栏独立滚动，避免导航到底部链接时带动整个外壳。浏览器用例显式检查切页及主内容滚到底部后提醒仍在视口内，不仅断言文字存在；截图 `.test-tmp/storage-threshold-notice.png` 已复查。

存储页原有扫描和清理流程保留。清理仍须已打开项目、预览候选和明确确认；修改提醒阈值不会触发或绕过清理。
