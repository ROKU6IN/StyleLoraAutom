## 本阶段范围

实现 F11 §9 独立服务容器的首批可用命令。当前用户没有正在运行的服务时，可以显式传入项目路径，打开自有 Runtime、完成查询或存储扫描，然后排空任务并关闭项目。默认仍附着已有服务，不自动切换项目或启动长驻进程。

| 命令 | 独立模式行为 |
| --- | --- |
| `source list` | 查询全部来源，自动读取分页 |
| `source status SOURCE_ID` | 读取持久来源状态；暂停/未知仍按原退出码报告 |
| `source items SOURCE_ID` / `source item ITEM_ID` | 查询全部来源条目或单项，不改变 attempts、不重发 |
| `source cost-state SOURCE_ID` | 查询本地费用状态，不确认费用或查询真实账户 |
| `job list` / `job status JOB_ID` / `job status --batch-id UUID` | 查询持久标注批次/任务，不运行推理 |
| `job outcomes JOB_ID` | 查询全部结果，可使用既有 kind 筛选 |
| `import summary SOURCE_ID` | 查询持久导入汇总 |
| `export list` / `export status EXPORT_ID` / `export report EXPORT_ID` | 查询持久导出状态和报告，不创建导出 |
| `storage scan` | 等待当前指定项目扫描完成，返回结果后关闭 |

以上命令接受 `--standalone --project PATH`，以及可选 `--runtime-dir`、`--product-dir`。路径解析与 serve/doctor 共用，产品目录影响配置、最近项目与私有目录；模型位置沿用 runtime 目录的既有规则。没有新增 HTTP 路由、数据库结构或产品配置格式。

```powershell
./scripts/run.ps1 source list --standalone --project "E:\datasets\demo.slproj" --limit 20
./scripts/run.ps1 source items 1 --standalone --project "E:\datasets\demo.slproj"
./scripts/run.ps1 import summary 1 --standalone --project "E:\datasets\demo.slproj"
./scripts/run.ps1 job list --standalone --project "E:\datasets\demo.slproj"
./scripts/run.ps1 export report <EXPORT_ID> --standalone --project "E:\datasets\demo.slproj"
./scripts/run.ps1 storage scan --standalone --project "E:\datasets\demo.slproj"
```

打开项目沿用 F01 的迁移、恢复、锁与登记协议：可能暂停中断任务、恢复可信本地收据、更新最近项目记录。这些命令不会启动生成、推理、下载或外部账户请求。需要不打开项目的诊断时可继续使用 doctor。

## 容器与生命周期

`runtime/standalone.py` 先取得当前用户 ProductLock，再解析目录、创建 Runtime、授予 project_open 并打开项目。已有服务或其它独立命令持锁时拒绝执行，不读取其管道凭据，不接管其项目。其它进程持项目锁时报告冲突并关闭新建的 Runtime。

请求通过 httpx ASGITransport 在进程内调用原 FastAPI 路由，复用参数校验、鉴权、项目 lease、后台任务与服务分派。鉴权凭据只在内存中使用；不创建监听 socket、PipeServer、浏览器引导链接或 instance.json。此阶段传输只允许 GET 和当前项目的 POST storage/scans，新增写操作需要单独扩展准入。

命令成功、业务失败、初始化失败或 Ctrl+C 时均执行容器清理。Runtime.shutdown 等待请求/任务排空，通过现有关闭流程暂停中断工作、清除费用周期、关闭项目。不会把独立命令描述为“退出后任务继续”。若关闭本身失败，返回 outcome=unknown、`service_closed=false`，在当前进程内保留排他，避免另一个容器进入。

输出保持单个 JSON；进度写 stderr。`cli` 追加 mode=standalone、service_started、project_opened、service_closed、session_reusable=false、打开阶段 recovery_counts，以及本次临时 instance_id/project_id。没有输出 Token 或配置绝对位置。结果里的会话句柄、版本和状态 URL 不授予下次进程的操作权限；后续查询应使用持久来源/条目/任务/导出编号及项目路径。

## 分页与参数边界

列表在同一容器中沿签名游标读取全部页。`--limit` 控制每次请求的页大小，聚合结果去除单页 limit，返回 next_cursor=null、has_more=false，并在 `cli.pagination` 报告 pages、returned、complete=true。最多 10000 项，累计 JSON 序列化大小最多 16 MiB；超限明确报错，不返回伪装完整的截断结果。重复游标、空页仍有后续游标或不完整终页被拒绝。

独立模式拒绝旧 `--instance-id`、`--project-id`、`--cursor`、`--idempotency-key`、detach 和最近项目批量扫描。没有 `--standalone` 时不能传项目/配置目录路径。未支持命令不接受这些选项，参数阶段即失败，不先打开项目。

预览与确认目前绑定 Runtime 会话。导入/导出/标注/生成的 preview/run、控制写入、清理和产品级 prompt 命令尚未接入独立模式；需要继续使用现有长驻服务。后续独立写流程需要补充跨进程可审核计划与持久请求对账，不会把旧会话计划直接改绑新项目句柄。用户要求暂缓的真实 NovelAI 小批量验收保持未执行。

退出码沿用 F11：成功且完成为 0，参数或结果上限为 2，产品/项目锁冲突为 4，依赖/I/O 失败为 5，部分结果为 6，暂停/未知为 7，正常中断并完成清理为 130。查询已暂停任务仍返回 7，不宣称任务已经完成。
