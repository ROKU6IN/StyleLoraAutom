# F14 工作台第一阶段：实现与验收

版本 0.4.0，2026-10-25。本轮依据 `F14-前端设计.md` 和 `F11-F14-API与进程设计.md`，将已有数据库、导入、标注、审核和导出能力接入浏览器。只在本地开发，没有初始化、提交或上传 Git。

## 已实现范围

| 页面/能力 | 当前行为 |
|---|---|
| 项目 | 创建、打开、修改名称/触发词、按住关闭；已打开项目重新授权后默认进入图片工作台 |
| 图片网格 | 200 项游标分页、按行虚拟化、焦点行保留、紧凑/舒适密度；审核/来源/评级/标签/缺失文件筛选，筛选写入 hash URL |
| 选择与审核 | 焦点和选择集独立；Ctrl/Cmd 多选、Shift 选择已加载范围；区分已加载项与完整筛选；K/X/U、方向键、最多 50 次本页审核撤销 |
| 人工标注 | 编辑合并标签，显式勾选写入自然语言；保存使用完整 read_set 和 If-Match，原始层保留；可查看各层标注 |
| 草稿保护 | 切换图片、导航和离开页面前确认；版本冲突保留草稿并显示远端内容，可显式合并标签增删再保存；断线/401 和图片被外部审核移出筛选时保留编辑器草稿 |
| 原图 | 鉴权 Blob 读取、原图拖动/缩放、上一张/下一张、五种背景、关闭后恢复网格焦点；透明标记依据后端信息 |
| 来源/导入 | Windows 目录选择、TXT 编码与递归选项、扫描预览、确认导入、来源计数/明细、暂停/继续/取消、重绑目录 |
| 导出 | keep 为默认范围，可包含 unreviewed、NL、JSON；预览最终标签、跳过与失败项；确认导出、取消运行任务、查看历史与落盘报告 |
| 任务 | 本进程任务列表、已完成/总数、未知总数不假装百分比、取消可取消任务；任务状态定时查询并由 SSE 提醒刷新 |
| 界面 | 浅色默认、暗紫深色/跟随系统、快捷键开关、审核自动前进；仅外观偏好进入 localStorage |

一次批量审核最多 5000 张，超限必须缩小范围，不自动拆分。查询范围预览冻结全部成员和逐图审核版本；提交时在同一个数据库写事务内重新核对集合、总数和版本。数量不变但成员被替换也会拒绝。撤销使用服务端返回的新版本；只有连续的本地版本链能够推进更早的撤销记录，外部修改仍产生冲突。

筛选全选保存的是筛选表达式。修改当前筛选不会改变该选择；不同筛选下不显示逐图选中高亮，执行前重新预览并确认实际数量。Ctrl/Shift 单项操作会退出筛选全选模式。选择“已加载”会切换为明确的 ID 集。

## 后端增量

| 路由 | 用途 |
|---|---|
| `POST /api/filesystem/grants` | Windows 原生选择器后台 operation，完成后返回受限路径授权；取消不产生授权；已有对话框时返回 409 |
| `GET /api/operations` | 当前项目和产品级任务分页；摘要不携带大型 result，通过单项 GET 读取结果 |
| `GET /api/projects/{id}/images/stats` | 与图片列表相同筛选条件下的总数和审核/评级/来源分组 |
| `POST /api/projects/{id}/images/review/preview` | 完整查询范围审核的短期预览 |
| `POST /api/projects/{id}/images/review` | 增加 query/expected_total/preview_id/digest 形式；原有 ids/targets 形式保留；结果增加 old_version 支持安全连续撤销 |
| `/`、`/assets/*` | 同源托管构建后的工作台；带 hash 的路由不需要服务端 history fallback；未知 API 仍返回 JSON 错误 |

F01 数据库 schema 仍为 v1、八张表，本轮不迁移数据。预览、授权、operation 与会话凭据继续是进程内状态。NativePicker 用独立隐藏控制台的 PowerShell/WinForms 辅助进程，项目内导入选择保持项目租约；取消或关闭服务会结束自己创建的辅助进程。

## 前端组织与运行

`web/src/api` 管理鉴权、错误、类型与媒体；`events` 解析 SSE、去重和限频失效；`state` 保存 React Query 和客户端选择/偏好；`ui` 提供公共组件；`features` 承载页面。颜色、间距与运行时网格几何集中在 tokens，图标为 SVG 文件，未引入 CDN 字体或整套 UI 库。

Bearer 只存在模块内存；一次性引导码读取后立即从 fragment 移除。不把 token 放进图片 URL、磁盘或 Web Storage。图片 fetch 并发最多 6，Blob 缓存按引用和 LRU 回收，项目切换撤销旧 URL。写请求不自动重试；断网造成未知结果时提示先核对任务和数据。

单条 SSE 通道支持 CRLF 分块、多行 data、心跳超时、epoch/sequence 去重、Last-Event-ID 重连、resync；业务查询合并到 300ms 窗口，刷新期间的变化会保留为下一轮刷新。GET 是最终依据，事件重连时使用轮询补偿。401 停止事件重连和写入，已有标注草稿仍可查看。

正常运行无需 Node：

```powershell
./scripts/run.ps1 serve
# 服务已运行时重新打开授权页面
./scripts/run.ps1 ui
```

修改前端时，Node >=22.22.2，在 `web/` 下执行 `npm ci`、`npm run build`。构建会替换本项目的 `src/stylelora/api/web_dist` 生成目录；Python wheel 含 HTML、JS、CSS、SVG 和 F01 SQL。

需要热更新时，在一个终端启动 `./scripts/run.ps1 serve --no-browser --dev-origin http://127.0.0.1:5173`，从就绪信息取 HTTP 端口；在另一个终端设置 `$env:STYLELORA_API='http://127.0.0.1:<端口>'` 后进入 `web/` 执行 `npm run dev`，最后运行 `./scripts/run.ps1 ui`。开发 Origin 必须是明确的 127.0.0.1 地址；生产部署仍为同源单服务。

从仓库根目录重新生成请求类型：

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
./.venv/Scripts/python.exe scripts/export_openapi.py
cd web
npm run api:types
```

请求模型从 FastAPI OpenAPI 生成，人工标注请求直接使用生成类型。F11 尚未为所有响应声明 Pydantic response_model，因此响应 DTO 暂时在 `api/types.ts` 显式维护，并由真实 HTTP 浏览器测试校验，未宣称全部响应均自动生成。

## 验证与复现

| 验证 | 内容 |
|---|---|
| Python 全量回归 | 原有 F01、文件闭环、F11 HTTP/单实例/关停测试，加工作台 API 测试 |
| 新增工作台 API 测试 | 完整查询与分页区别、同数量成员替换、逐图版本冲突与原子性、空范围/输入验证、预览绑定、统计、任务分页、目录选择互斥/取消/租约、静态资源、撤销前后版本 |
| Vitest | SSE 分块/去重/预算、300ms 合并、选择集、草稿规范化/显式合并、输入快捷键保护、审核排队与版本链、未知结果不重试、Blob 并发/回收、10000 项网格挂载少于 80 个单元 |
| Playwright / Edge | 创建→导入 6 张合成图片→草稿保护→保存→原图→审核/撤销→导出，检查实际 TXT 和报告；并发冲突、主题/密度、读屏名称、axe 严重/致命问题零项、刷新再授权；断线/401/外部审核移出筛选时草稿保留 |
| 静态与构建 | TypeScript strict、ESLint 零警告、设计边界检查、Vite 生产构建、Python wheel 资源和包内 HTTP 回归 |

浏览器测试数据、日志和截图均在 `.test-tmp`，不包含真实用户图片。测试仅关闭自己创建且 PID 已核验的服务，不接管用户已有服务。Windows 系统目录对话框在浏览器测试中使用测试专属 chooser 替身；目录授权、operation、文件扫描与全部后续业务仍执行真实实现。原生对话框本身的交互验收不由这组无头浏览器测试覆盖。

测试命令：仓库根目录 `./scripts/test.ps1`；`web/` 内依次执行 `npm run lint`、`npm test`、`npm run build`、`npm run test:e2e`。本地日志为 `.test-tmp/f14-all-python.log`、`f14-unit.log`、`f14-lint.log`、`f14-browser.log` 和 `f14-wheel-tests.log`。

最终结果：193 项 Python 全量回归通过，无跳过（原有 181 项加本轮 12 项）；22 项 Vitest 通过；4 组 Playwright/Edge 验收通过；TypeScript、ESLint 零警告和设计边界检查通过；生产构建成功。0.4.0 wheel 内 20 个前端资源与当前构建逐字节一致，SQL 与包导入位置核验通过，从解包目录运行 31 项 HTTP 测试通过。测试服务已正常退出。

Vitest 的 10000 项测试证明 DOM 挂载受限，不等同于真实万图磁盘吞吐或浏览器帧率验收。当前 Starlette TestClient 仍会提示 httpx 将被替换的弃用信息，测试未跳过，也未隐藏该警告。
