## 编辑范围

入口仍为“提示词生产 → 本地词典”，不新增独立草稿注册。特征词典可新增、重命名、删除维度，每维候选可新增、复制、修改、排序及删除；维度重名拒绝覆盖或隐式合并。提示词可逐项编辑有序标签（每行一个）、多行自然语言、图幅与评级，支持新增、复制、排序及删除。评级缺省为未知，图幅允许未指定；表单不推断评级，也不将未指定值转为 general。

每页只渲染 20 行，检索标签、描述和评级，保存仍使用完整草稿。列表行绑定原始位置，跨页或检索后编辑不会写到另一个条目；有检索条件时关闭上/下移，清空后按原始顺序移动。特征维度最多 20 个，词典合计最多 10000 条，提示词最多 100 个标签、描述最多 4096 字符，沿用后端限制。空提示词词典允许保存，空维度或空特征词典拒绝保存。

表单与“高级 JSON 编辑”共用父级 content 草稿，没有独立待应用副本。输入中的空行、空标签和暂时未命名维度保留供继续编辑；保存前给出最多 20 项基础诊断，语法、控制词和结构以已有服务端严格校验为准。未知字段、错误枚举或非法 JSON 不被表单重写、删除或自动修正，原文保留在高级编辑区。服务端继续执行规范化与去重。

删除条目/维度先显示范围确认，只修改草稿；可立即撤销最近一次删除。进一步编辑使该撤销失效，避免恢复旧草稿时覆盖新工作。切换条目、分页与检索不丢编辑。切换词典、新建、离页、重新载入继续使用统一草稿保护；保存失败不能通过“保存并继续”放行。后台列表刷新不会覆盖当前草稿。断线或保存期间禁用编辑。

## 保存、冲突与结果

不新增写接口，继续使用 `POST /api/prompt-production/dictionaries` 与 `PUT /api/prompt-production/dictionaries/{id}` 整体保存。PUT 使用当前 version 和 UUID 请求键，服务端以单个词典文件的原子替换同时写入内容、revision 和请求凭据；没有逐行部分提交。

保存失败保留完整草稿。同一正文、词典与基准版本重试复用原请求键；收到响应前连接中断时，重试通过持久凭据返回已保存结果，revision 不重复增长。版本冲突保留草稿并报错，不自动用新版版本重写旧草稿；“重新载入已保存词典”须通过未保存草稿保护。

成功后读取已保存词典并显示版本、合并重复条目数量与评级合并报告。特征同维度规范标签重复按既有规则合并，评级取较高者并提示。提示词重复键仍为规范标签集合、规范描述、图幅，相同内容不同评级拒绝保存；描述/图幅不同可独立保存，批次采样仍按标签集合去重。画风、作者、权重等内容限制继续由已有采样/复验规则处理，词典编辑不等于生产结果已通过内容检查。

改动词典不会改写已创建任务、覆盖方案、已导出文件或已交接生成源。字段类型、词典运行文件、导入导出格式、任务快照和 HTTP API schema 均保持原合同。本轮无需新模型调用或外部数据。
