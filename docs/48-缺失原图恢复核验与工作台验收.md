# 缺失原图恢复核验与工作台验收

日期：2026-10-28；版本：0.41.0。仅本地开发，不初始化、提交或上传 Git，不调用真实生成服务。

## 本轮范围

接续存储清理，落实 F01 §5.4/§6 的 missing 解除约束和 F11 A065。用户先从自己的备份将原文件放回当前项目的 `images/<原文件名>`，再显式核验。工作台筛选“文件缺失”、选择图片后，详情显示所需相对位置和“核验已放回的原图”按钮。

本功能不自动寻找备份、不复制/上传文件、不重新生成或下载图片，不接受任意路径；没有备份时不能还原已清理的字节。即使文件已放回，普通 GET、媒体读取和打开页面也不会自动清除已保存的 missing 标志。

## API 和后台任务

`POST /api/projects/{project_id}/images/{image_id}/verify-file`，请求体为严格空 JSON `{}`，要求 If-Match（当前 ImageView.version）和 Idempotency-Key。多余 body/query 字段拒绝；沿用 Bearer、Host、Origin 与项目句柄校验。受理返回 202 Operation，kind 为 `image.verify_file`；session.capabilities 增加 image_file_verification。

受理前读取图片行并校验版本；后台执行前以及 writer 内再次校验。请求键摘要包含 If-Match，同键同版本返回原任务，不重复核验；同键不同版本报冲突。失败任务不会自动重跑，修复文件后须明确新建一次核验。任务保留项目引用，关闭项目等待已受理任务退出；取消在文件读取和提交前检查，已经完成的数据库提交不会被撤销。

核验完成返回 image、changed、verified_sha256、verified_bytes、as_of。即使 missing 已为 false 仍核对真实文件，正确时 no-op，版本和图片事件均不变化。发生变更时在提交后增加图片版本并发布 image.updated，载荷只有图片编号和 file_missing 字段名，不含路径或文件内容。

## 文件和事务边界

服务只使用数据库记录的文件名、大小、SHA-256。与导入、媒体、导出和清理共用项目文件锁；冲突立即返回 storage:leased，不占着 worker 无限等候。采用 1 MiB 块读取，最多 100 MiB；大小或 SHA-256 不符报 image:hash_mismatch，保持 missing。缺文件、不可读、占用、链接或目录身份变化分别失败，不删除、不替换文件。

Windows 核验打开项目根及 images 目录句柄，禁止目录删除/改名；原图句柄仅共享读取，禁止并发写入/删除，并拒绝既有写句柄。使用 OPEN_REPARSE_POINT、最终路径检查、目录/文件身份和 stat/fstat 复核，拒绝 symlink/junction 等替换。句柄一直持有到 writer 提交完成；DAL 的 set_file_missing 仍自行二次核对大小和哈希，不接受客户端哈希作为解除凭据。

非 Windows 路径保留非跟随打开及身份复核，但本轮外部文件并发保护实机验收针对 Windows；不宣称这些检查能阻止提交完成、文件句柄释放后的外部修改。后续读取仍走原有媒体哈希校验。原图无任何写入，既有硬链接内容也不会被修改。

成功仅清除 file_missing；原 review_status、评级、来源、图片身份、标注及历史保留。剔除图片核验后仍为剔除，用户须另行决定是否保留再导出。缺失图原先为 keep 的，保持其原有决定。SQL 失败则回滚；提交完成但回包异常保持结果未知，通过只读图片状态核对，不发未确认的成功事件。没有 DDL 变更。

## 前端行为

仅缺失图片或当前会话存在核验记录时展示核验面板。提交期间和任务执行期间禁用新核验；轮询错误保留受理编号，可显式查询结果，不重发 POST。成功显示历史核验时间并刷新图片、筛选、统计与标注视图；不声称历史结果是持续监控的文件健康状态。缺失筛选中的图片恢复后离开结果集，聚焦详情继续保留。

请求回包未知时，当前会话查询缓存保存原请求键和图片版本；切图或导航回来仍禁止新核验。“找回原核验任务”只显式提交同键同版本请求，由服务返回原受理任务。后台数据库提交结果未知则另提供“核对图片状态”，只 GET 当前图片；核对前禁止新核验。浏览器刷新或项目重开后不得把旧请求键视为跨会话凭据，需先从任务记录/图片当前状态核对。

核验不改变标注版本引用，已有未保存草稿不会被刷新覆盖。离线、重新认证和服务关闭阶段禁止提交。任务页使用“核验恢复原图”中文名称，仍可通过现有任务控制查询或取消可取消的在途核验。
