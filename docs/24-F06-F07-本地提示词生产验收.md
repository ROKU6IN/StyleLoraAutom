# F06/F07 本地提示词生产第一阶段

版本 0.17.0，2026-10-26。依据 `F06-F07-提示词生产设计.md` §4–5、§7–9，完成本地词典 → 覆盖预览 → 持久采样任务 → 冻结 JSON 的闭环。仅本地开发、测试与构建；没有初始化、提交或上传 Git，没有调用外部 LLM、Launcher 或 NAI。

## 已实现

| 模块 | 行为 |
|---|---|
| 产品词典 | features/prompts 两种类型；创建、读取、编辑、分页列表；revision CAS；写请求凭据随文件原子保存 |
| 交换 | JSON/CSV 结构往返；TXT 特征按指定维度与可选评级解析；TXT 提示词通过本地标签索引区分 tags/NL；逐行预览，存在任意错误整批拒绝追加 |
| 覆盖 | 2–3 主维、格子保底 1、正整数权重及最大余数法；整体比例和数量上下界取交集；显式排除规则；关闭覆盖仍保留整体约束和围栏 |
| 候选 | 合并多个完整提示词词典和特征组合池；来源权重为偏好；相同词典副本不加权，批内严格按规范标签集合去重 |
| 检查 | 标签规范化、可信别名、显式评级与本地关键词最高值、未知评级提示、围栏、字面禁用词和作者分类拦截；不会自动调用分级模型 |
| 任务 | 独立产品文件、冻结词典/规则/标签映射/种子/运行时版本；后台运行、暂停/继续/取消；取消丢弃迟到结果，重启转暂停且须显式继续 |
| 输出 | 全量分页结果；满足数量、内容、去重和覆盖后输出完整连续 seq=1..N、prompt/aspect，含摘要；不向 project.db 写任何行 |
| 界面 | 全局“提示词生产”页面，词典结构编辑、文件预览追加、采样条件、覆盖与缺口报告、历史任务、控制及 JSON 下载；保留草稿和未知请求身份 |

默认 UI 模板显式列出 scene×lighting 六格、无人物至少 15%、远景至少 10%。`no_humans_excludes` 是 Plan 的显式版本化列表，用于“no humans 时不抽 appearance/clothing/pose/expression”；不是根据维度名称暗加的通用规则，不能删除主维。纯 API 默认 constraints 为空，只有选择模板才带入比例。

预览用独立 Random(seed)，候选先按规范键排序；冻结后与文件枚举顺序无关。主维/约束/排除条件使用同一份冻结别名映射。候选最多 10000 个，搜索最多 100000 个节点；全枚举且搜索穷尽才报告 unsatisfiable，预算截断报告 search_exhausted。下界使用十进制 ceil、上界 floor，避免浮点边界误差；比例可重叠。候选顺序只决定偏好，回溯仍检查精确配额及所有约束。搜索使用迭代栈，不依赖 Python 递归深度。

字典内容去重键包含规范标签集合、折叠空白的 NL 和 aspect；相同内容的不同评级拒绝自动覆盖。特征同维同标签的评级冲突取高并报告。批内只以标签集合去重，NL/aspect 差异不能绕过。未启用精修时保留词条原有 NL/aspect，不虚构描述或像素尺寸。

## 持久化与并发

默认产品根目录 `%APPDATA%/StyleLoraAutom/`，文件分布在 `dictionaries/features`、`dictionaries/prompts` 和 `prompt_tasks`。使用测试/CLI product-dir 时与现有 LLM 产品目录共同隔离。磁盘文件使用 `{content,digest}` 完整性信封，公开 JSON 导出使用设计文档的词典信封，不包含 `_operations`；文件不是项目溯源数据。

写入采用同目录临时文件、flush/fsync、replace；同进程产品写锁串行化。读取拒绝链接路径、超限文件、摘要不符和不符合 schema 的内容。每组最多 2048 个文件、单文件 64 MiB、冻结输入 32 MiB、每词典最多 10000 条、每文件写凭据最多 4096 个，达到上限明确拒绝。没有自动删除用户历史文件。

字典写请求先检查持久凭据，再做版本 CAS。导入确认凭据绑定 preview_id/digest；提交响应丢失后即使会话预览已过期，原请求仍可核销。未知写入会核对 replace 后文件是否已经等于目标内容，确认落盘才报成功。创建词典和任务由客户端提供 UUID，配合同一 Idempotency-Key 重放；同键用于不同对象/内容拒绝，不再创建第二个任务。

创建任务必须提交覆盖预览摘要及包含实际随机种子的请求。服务端重新冻结并核对词典/标签库/规则/计划，任何变化拒绝旧预览；任务启动后只读自己的快照。后台任务属于产品层，无项目租约；关闭项目不改其输入。普通后台 operation 取消入口不控制持久采样任务，需走专用控制 API。

本阶段没有远端在途请求，本地搜索可从冻结快照重算。任务重启后暂停；已完成结果保持原样。Python 版本不匹配时仍可读历史结果，拒绝重新采样。损坏任务文件保留，列表显示不可用，单独查询报错，不自动重采样覆盖，也不阻断其它任务。断电/进程退出跨目录 fsync 的平台差异仍由既有原子文件层承担。

## HTTP 与界面合同

全部为产品级 `/api/prompt-production`，继承本地鉴权、Origin 校验、请求体上限和错误脱敏。不会接受任意文件路径、模型 URL 或生成源 ID。

| 路径 | 方法及说明 |
|---|---|
| `/capabilities`、`/launcher/capabilities` | GET；明确只支持本地阶段，Launcher 未核验不可用 |
| `/dictionaries`、`/dictionaries/{id}` | GET/POST、GET/PUT；编辑 If-Match，写入 Idempotency-Key |
| `/dictionaries/{id}/export?format=json\|csv\|txt` | GET；JSON/CSV 无损，提示词 TXT 说明丢失 aspect/rating/结构；特征多文件 TXT 暂不开放 |
| `/imports/preview`、`/dictionaries/{id}/imports` | POST multipart 预览、POST 确认；最大 10 MiB、严格 UTF-8/BOM；最多显示 100 个诊断，但错误门禁检查全部行 |
| `/coverage/preview` | POST SamplingRequest；只读，返回报告和最多 100 个样例，无解/耗尽仍以 200 报告供界面展示；非法输入 422 |
| `/tasks`、`/tasks/{id}` | POST 202 / GET 列表、GET 状态；任务列表和 outcomes 默认 200、上限 1000；游标绑定内容版本 |
| `/tasks/{id}/control` | POST action + expected_revision；终态不能重开，重复目标幂等 |
| `/tasks/{id}/outcomes`、`/tasks/{id}/seeds` | GET 分页结果、POST expected_revision 获取冻结全量；未就绪返回 409 |

事件复用 `/api/events?topics=prompt&resource_id=<id>`；只发 ID/状态/revision/ready 摘要，事件缺口重新 GET，界面保留轮询。未另外复制任务专属 SSE 路由。

浏览器编辑采用 JSON 结构表单，提供可直接修改的特征/覆盖样例。修改采样条件立即取消旧确认；字典外部修改由创建时摘要检查拦截。请求结果未知时保留原 UUID 和请求键。浏览器输入种子限制为 JavaScript 精确整数范围；省略种子时生成可被浏览器无损往返的 53 位非负整数，属于 uint64 的合法子集；API 仍接受完整 uint64。JSON 结构交换优先，普通 prompt 字符串中的逗号不可保证无损重建 tags/NL，报告提示未知标签和 NL 碰撞。

## 验证

本轮新增 26 项后端用例包含：严格输入/规范化、字典 CAS 与原子写故障、replace 后未知结果核销、跨文件请求键冲突、JSON/CSV 往返、101 行以后的错误与样例范围之外的内容摘要、预览过期后的追加重放、六格 100 条精确配额、重叠比例与无人物模板、预算耗尽区别于无解、30 组小候选穷举对照、重复词典不加权、围栏和禁用内容、205 条完整分页、任务冻结/暂停/取消/重启/版本差异/损坏隔离、鉴权及未开放能力。

截图复核后调整了下限约束的搜索启发式：每格先尝试少量按配额比例分配的稀缺标签，再保留其余候选的随机/来源优先序；不会因“至少 15% 无人物”而把全部无人物候选永久前置。这只是候选排序，不增加隐藏比例硬约束；新增固定样例的多样性检查，并保留精确配额、上下界与穷举对照。

前端新增 7 项测试覆盖结构表单、整数种子、旧预览失效、未知创建请求身份、CAS 冲突草稿、未就绪导出门禁、搜索耗尽提示。Edge 新增两条真实本地 HTTP 流程：词典 → 100 条覆盖 → 持久任务 → 实际下载冻结 JSON；词典变更 → 旧预览拒绝建任务 → 错误 CSV 无写入。
