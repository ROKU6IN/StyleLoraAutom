# F11 显式网络诊断验收

版本：0.56.0。日期：2026-10-29。实现 F11 §9 的可选 `--probe-network`，保留 T42 默认不访问外部服务的约定。

## 命令与范围

```powershell
./scripts/run.ps1 doctor --probe-network --json
./scripts/run.ps1 doctor --probe-network --network-timeout 30 --json
./scripts/run.ps1 doctor --project "E:\datasets\example.slproj" --verify-content --probe-network --json
```

只有显式传入 `--probe-network` 才会读取已配置的有效凭据并发送网络请求。不加该选项，包括仅使用 `--verify-content` 时，均不解密保存的凭据、不访问外部端点。CLI 不接受明文 Token 或任意探测 URL；复用已保存的端点配置及原有环境变量/DPAPI CurrentUser 凭据来源。

首版覆盖两类固定只读请求：

- LLM：每个已配置端点最多一次 `GET base_url/models`，沿用 OpenAI Chat、OpenAI Responses、Anthropic Messages 的认证头。读取配置中第一个有效凭据；不存在或无效的环境覆盖值不会偷偷回退到同一引用的存储值。请求失败后不切换到第二个凭据，不重试。
- NovelAI 直连：有已保存 Token 或环境覆盖时，复用现有客户端，只访问固定官方 `GET https://api.novelai.net/user/subscription`。响应仅用于验证结构，丢弃余额、订阅和账户字段，不写入 UI 缓存、不执行费用估算或生成。

没有配置的可选服务返回 `doctor:not_configured`、退出 0、`attempted=false`。有配置但缺少有效凭据返回 `doctor:credentials_missing`、退出 7。LLM 端点超过 16 个时整组不发出请求，报告数量与上限、退出 7，不静默选择前 16 个；直连账户仍独立诊断。Launcher/MCP、WD 下载源、真实图片/文本生成及供应商费用/质量验收不属于此入口，仍使用既有专用流程。

## 快照、网络和完成语义

读取配置/凭据时复用原有 schema 验证和有大小上限的只读文件句柄。完成快照后即释放全部文件句柄，再串行执行 HTTP；不在等待网络期间阻止用户保存设置。一次诊断固定该次读取到的 URL、协议和凭据，期间的配置改动不重定向在途检查。只检查连接与响应契约，不创建 Runtime、附着本地服务、打开项目、修改模型列表或写审计/账户文件。

`--network-timeout` 必须与网络选项同用，允许 5–120 整数秒，默认 30。预算从网络阶段开始计时，全部 LLM 和直连请求共用；每个请求使用剩余时间，耗尽后后续端点返回 `doctor:network_budget_exhausted` 而不发送。HTTP 客户端还有连接/读取上限，直连保留既有账户读取至多 30 秒的内层限制。操作系统调用和协作式取消可能延迟退出，不将其描述为可强制终止线程的硬截止时间。

禁止代理环境、重定向和自动重试。LLM 请求要求 HTTP 200、JSON MIME、identity 编码，声明大小与流式内容均不超过 1 MiB；拒绝坏 JSON、重复键、错误模型标识和异常分页标志，每页最多 1000 个模型。只报告当前响应的数量与 `more_models`，不自动翻页、不返回模型名称。NovelAI 沿用固定主机、JSON MIME、64 KiB 上限和现有账户结构验证。

超时取消并等待当前协程退出；Ctrl+C 关闭请求并退出 130，不输出完整成功 JSON。GET 在中断前可能已抵达服务端，但不会补发或提交生成。任何接口成功都不证明推理能力、账号余额足够或未来生成免费。

## 报告和退出码

启用网络检查时 `scope=local_and_network`、`network_requested=true`；`network_probed` 表示至少尝试执行了一项请求，不代表服务器一定收到。`content_verification_requested` 表示是否同时启用模型/数据库内容检查。完全未配置或全部检查均未发送时 `network_probed=false`。`repairs_performed` 始终为 false。

每个网络结果给出固定检查编号、`probe`、`attempted`、`reply_valid`、`credentials_accepted`、`read_only=true` 与 `generation_performed=false`。尚未发送的配置/凭据检查只提供适用字段。`credentials_accepted=true` 表示带凭据请求取得符合预期的成功响应，false 表示明确认证拒绝，null 表示不能判断；不宣称公共端点一定执行了鉴权。LLM 检查编号携带已有 endpoint UUID 以便定位，不输出 URL、凭据引用/变量名、Token、模型名称、账户内容、绝对路径或原始异常。

| 情况 | 退出码与结果 |
| --- | --- |
| 响应验证通过 | 0，`doctor:network_verified` |
| 无可选配置 | 0，`doctor:not_configured`，没有发送 |
| 参数/组合不合法 | 2，解析阶段结束 |
| 认证、限流、网络、配置、响应或依赖错误 | 5，固定安全错误码；直连保留 `nai:*` 既有错误分类 |
| LLM 模型列表接口返回 404/405/501 | 6，`doctor:network_probe_unsupported`，不据此断言生成接口不可用 |
| 缺凭据、端点超限、总预算超时或耗尽 | 7，需要处理；后续请求不发送 |
| 用户中断 | 130，不输出完整成功报告 |

直连客户端自身的连接/账户超时可返回既有 `nai:account_unavailable`（5）；外层总预算到期为 `doctor:network_timeout`（7）。汇总继续按 5、4、7、6、0 排序；某个网络结果失败不覆盖已有本地检查结果，也不阻止其他独立诊断。运行器出现不可预期故障时报告安全错误码及 `request_state=unknown`，不回显异常或把请求假定为未发送。
