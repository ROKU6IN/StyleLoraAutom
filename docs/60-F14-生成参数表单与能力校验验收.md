# F14 生成参数表单与能力校验验收

版本：0.53.0。日期：2026-10-28。对应 F14 §4.2–4.3、F02–F05 的能力描述与明确参数配置要求。

## 已实现

来源页的 NovelAI 直连草稿使用后端能力描述渲染表单：模型枚举、默认图幅、实际像素尺寸、步数、引导强度与 CFG 重缩放均可编辑；当前协议固定的采样器、档位和高级开关只读，并说明原因。数值提供范围/步进提示与辅助滑块。读取能力、编辑和保存草稿无需 Token，不调用上游账户或生成接口。

生产前端不再复制直连参数清单或默认配置。`GET /api/backends/nai_direct/capabilities` 在原能力字段之外提供 `form.version=1`、`default_config`、字段标签与提示；参数限制仍唯一来自原 `config_schema`。展示元数据与默认值不参与生成协议摘要，内部驱动继续使用原四字段能力合同，既有 response 回执恢复依据不变。

表单与高级 JSON 共用配置，切换当前支持的两个模型保留同名字段。输入空字符串、未完成的小数或越界值会保留并报错，不自动归零或裁剪；未知字段不会被表单修改删除。后端描述刷新不覆盖已有编辑。尺寸预设复制实际像素，超出当前能力时明确拒绝，保留原配置。

保存直连草稿时，后端再次校验模型、固定值、数值范围和尺寸范围。失败返回 422 与字段路径，例如 `config.profile.steps`，前端将错误回显到对应控件；错误消息不包含提交值。Pydantic 的 `body.config…` 路径也会映射。更新仍先检查原版本和锁定状态，失败不改变草稿或版本。

已有 Launcher 草稿保留原后端和参数；没有兼容能力描述时保留高级 JSON 编辑。未知 schema 规则或展示版本退化为只读配置展示与提示，不擅自忽略新规则生成可编辑控件；仍可明确使用高级 JSON，由后端最终校验。

## 边界

这次完成当前直连协议的参数表单。两个现有模型共用参数结构，没有需自动删除的模型专属字段。完整条件 schema、引用、数组、复杂依赖与未来模型的字段迁移仍未开放；遇到这些描述使用上述退化路径。默认图幅沿用 0.52.0 的 portrait，不改变旧来源。

没有新增模型、采样器、参考图、角色提示词、img2img 或批量请求。真实 NovelAI 生成、实际扣费、20 张连续运行与真实账户重启恢复仍需另行验收。能力校验和表单通过不代表上述项目已验收。
