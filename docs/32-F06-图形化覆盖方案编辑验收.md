## 编辑与预览

入口“提示词生产 → 管理覆盖方案 → 使用表单编辑”。支持方案名称、目标数量、随机种子、2–3 个主维度及逐行取值，整体标签比例/数量上下界、排除谓词、no_humans_excludes。整体上下界按最终标签集合计算，同标签多条约束取交集；约束中的 dimension 沿用现有分类字段语义。比例与数量同时填写时取更严格限制。空数量界限与 0 有区别。

矩阵每页最多 10×10 个格子，可交换行列、选择第三维切片、分别翻页，通过鼠标或键盘选择格子修改相对权重。每个有效格先分配一条，再按权重和冻结种子分配余量；不提供直接指定某格固定配额。规则和数值改变后旧配额失效，必须明确重新预览。未固定种子时只显示有效格子和约束范围，不伪造确定的随机余数分配。

“按当前格子标签新增排除条件”生成 all_tags 谓词，允许继续编辑 all_tags/none_tags；按标签集合匹配，可能影响多个格子，页面明确提示。任何一项谓词命中即排除；两个列表皆空会排除全部。只涉及主维度标签的谓词参与格子排除，其余仍在实际候选层执行。被排除格如仍有自定义权重，会提示恢复默认；不会偷偷删掉权重或放宽规则。

主维度重命名会迁移对应规范 cell_id 的权重，重复名称拒绝而不覆盖其他维度。删除主维度需确认；修改取值、新增或删除维度后原权重保留，失效项有明确数量与手动清理按钮。其他约束、排除谓词和无人物兼容维度不自动改写，需用户核对。规则最多 10000 格、100 个排除谓词、100 条约束，沿用既有上限。

## 数据一致性与接口

新增纯投影模块 `prompt_production/coverage_editor.py`；从 sampling 抽取 coverage_cells，共用原格子排除、quotas 和 constraint_bounds 算法。预览不读取词典、不构造候选池、不调用模型、不创建任务、不写方案文件或请求凭据。格子有效、配额可分配不代表候选可满足约束；保存并载入采样页后仍须执行实际采样预览。

| 方法与路径 | 行为 |
|---|---|
| POST `/api/prompt-production/coverage-plans/editor` | 接受既有 format/content，严格解析 JSON/YAML；返回规范模板文本、字符串数值表单和布局 |
| POST `/api/prompt-production/coverage-plans/editor/preview` | 接受表单；严格转换数值并通过原 Template/Plan 校验，返回规范模板与新配额布局 |

所有可编辑数值在表单协议中为字符串，避免 uint64 经 JavaScript Number 舍入，并允许暂存空值/输入中间态。种子精确支持 0–18446744073709551615；空串转换为 null。整数不接受指数、负号、小数或 Unicode 数字；比例支持十进制与科学记数，要求有限且处于 0–1。不会把非法字符串转为默认值。浏览器采样页仍限定安全整数，该边界未改变。

保持原模板校验：未知字段、重复键、YAML 锚点/别名、自定义对象、非法标签和失效权重拒绝；转换失败保留原草稿。数值转换后再做 1 MiB 规范内容检查。接口沿用会话鉴权、Origin 边界、严格查询字段，OpenAPI 和前端类型同步生成，能力增加 coverage_editor。

文本和表单同一时刻只呈现一种编辑表示。进入表单先由服务端解析原文；切回文本或保存时由服务端产生精确模板字符串，前端不解析其中的 uint64。保存继续调用原 POST/PUT API，保留版本 CAS 和原子写入。未知保存结果用相同请求键重试，草稿变更才换键。保存后若读取到其他窗口新写入的版本，会从该版本重新构造表单，避免旧字段搭配新版本号。冲突保留草稿，离页/切换/重新载入继续使用“保存并继续 / 放弃草稿 / 继续编辑”；非法草稿保存失败会留在原页。未保存时禁用导出。修改方案不影响已创建任务快照。
