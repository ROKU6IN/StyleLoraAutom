## 在新环境重建

准备 Windows、Python 3.11+（本机验收使用 3.12）和 Node >=22.22.2。以下命令在导出目录运行，需要联网下载依赖；本次导出未执行下载或调用生成服务。

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -e .
Push-Location web
npm ci
npm run build
Pop-Location
./scripts/run.ps1 ui --start-service
```

前端 build 会生成 web/dist，并复制到 src/stylelora/api/web_dist，之后才具备完整本地工作台。若制作 wheel，应在前端构建之后运行 pip wheel。

需要 WD CPU 推理时，再安装 `./.venv/Scripts/python.exe -m pip install -e ".[wd-cpu]"`，并在模型管理页显式安装/校验模型。GPU 使用独立环境和 wd-gpu 依赖，不要在同一环境混装 CPU/GPU 两种 ONNX Runtime。账户密钥只在新机器的本地设置页配置，不随源码复制。

旧验收文档引用的 .test-tmp 日志、截图和模型文件不在净化副本中，仍保留于原开发目录；文档中测试结论属于既有本机验收记录，不表示新机器已经复验。scripts/check_wheel.py 使用的 .test-tmp/wheels 目录也需要在重新构建时创建。
