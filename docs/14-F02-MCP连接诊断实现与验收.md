# F02：MCP 传输基础与连接诊断

日期：2026-10-25。版本：0.7.0。接续 [方案解析阶段](13-F09-F10-方案解析实现与验收.md)，实现 [F02–F05 设计](F02-F05-生成后端设计.md) §3 中可独立验证的发现、传输、兼容检查，以及 F11 的后端查询与 F14 的 Launcher 设置入口。仅本地开发，不初始化、提交或上传 Git。

本阶段交付的是 F02 基础，不是 F02–F05 生成闭环。生产兼容清单仍为空：设计文档中的 v4.3.0 只是候选，仓库没有经过核验的真实工具 schema，不能使用合成测试哈希冒充兼容。本机未发现 Launcher 的发现文件；真实 Launcher 端到端、实际生成与费用行为未验收。

## 已实现

- `backends/nai_launcher/discovery.py`：从 `%APPDATA%/nai-launcher/mcp-server.json` 读取 endpoint、port、pid、protocol_versions、app_version 与凭据。严格匹配 `http://127.0.0.1:<port>`，拒绝查询参数、重定向路径、符号链接或 junction；发现文件最多 64 KiB。文件不存在或写到一半时最多读 3 次，间隔 50 ms。显式运行时 token 优先于环境变量 `NAI_LAUNCHER_MCP_TOKEN`，再使用发现文件 token；空的高优先级凭据不静默回退。
- `client.py`：初始化、initialized 通知、分页 tools/list、Bearer/session/protocol 请求头；JSON 与增量 UTF-8 SSE，处理 CR/LF、注释、多个 data 行、通知和不同请求 ID。空 200、未完成 SSE、错误 ID、重复 JSON 键、非有限数值都不视作成功。禁用代理与跳转，要求未压缩响应，限制累计响应 16 MiB、工具最多 10,000 个 / 32 页。
- 请求 JSON 完整包络最大 8 MiB，等于上限允许。调用前冻结参数和检查大小。工具只按经审核的静态读写分类派发，不采纳服务端 annotations 来提升写权限；未核验契约拒绝调用。
- 初始化连接超时默认 10 秒，整次握手和读取默认 30 秒；写工具默认 660 秒。总期限不被心跳延长。读请求最多额外重试 3 次，指数退避并带 25% 抖动；尊重有界 Retry-After。404 会话失效只允许一个协程重建，并重新读取发现文件；并发读上限 2，写串行。
- 已发送写请求遇到 404/502/超时/断开/不完整响应等任何失败，绝不自动重发，返回 `mcp:write_outcome_unknown` 并保持逻辑写屏障。后续只允许核查读取；重连不清除屏障。取消通知仅请求取消，不证明副作用停止。关闭客户端在屏障存在时保留警告，不用 DELETE 冒充已撤销；正常关闭接受服务端已关闭的 404。
- `compatibility.py`：按工具名排序，对输入/输出 schema 规范化计算核心和完整 SHA-256；精确比较 app/server/protocol 版本与两个摘要。缺核心工具、未知版本、未知结构均不可用。生产 `REVIEWED_CONTRACTS` 为空，测试可信契约只在测试代码内显式注入。
- `services/backends.py`：显式、单次、可取消的后台检查；不依赖打开项目；并发点击复用当前任务。检查只调用 initialize / notifications/initialized / tools/list，完成后关闭诊断会话。结果只包含固定原因码、受限版本号、已知核心工具名、数量与摘要；不返回 token、endpoint、服务器消息或原始 schema。取消保留上次结果。重启后状态回到尚未检查。
- 工作台侧栏“Launcher / MCP”：检查、取消、最近检查时间、服务可达性、兼容性、工具数量、摘要和错误原因。检查结果是缓存快照，不冒充持续在线；明确显示“生成尚未启用”。刷新与重新进入页面不会自动调用 Launcher。

MCP 传输与生命周期参照官方 [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports) 和 [Lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)。当前实现协商 2025-11-25、2025-06-18 或 2025-03-26；支持协议日期并不代表接受某个 Launcher 工具契约。

## HTTP 与本地使用

全部接口仍受本地 API Bearer、Origin、请求大小及进程状态检查保护。

| 接口 | 当前行为 |
| --- | --- |
| `GET /api/backends` | 已注册后端的缓存诊断与最后一次 probe operation ID；无文件或网络探测副作用。当前只注册 nai_launcher。 |
| `POST /api/backends/nai_launcher/probe` | 本阶段新增诊断接口；严格空对象请求，UUID Idempotency-Key，202 返回 operation/status_url/events_url。 |
| `GET /api/backends/nai_launcher/capabilities` | 尚未核验时 503 `backend:incompatible_schema`；即使测试中注入已核验契约，也因生成适配器未实现返回 503 `backend:generation_unavailable`。不猜测模型与参数。 |
| `GET /api/backends/nai_launcher/account-status` | 返回 null；可选 project_id/source_id 做项目和来源校验，来源不匹配返回 422。不产生余额或费用估算。 |
| `GET /api/operations/{id}`、`POST /api/operations/{id}/cancel` | 沿用 F11 查询、CAS 取消机制；检查不可达也可正常完成，诊断结果用 status/reason 表达；任务取消则 canceled。 |
| `GET /api/events?topics=backend` | `backend.changed` 只通知状态变化，GET 缓存为权威结果。 |

前端路由 `#/settings/launcher`。命令行与浏览器共用同一后台任务：

```powershell
./scripts/run.ps1 serve
# 第二个 PowerShell 窗口：
./scripts/run.ps1 api POST /api/backends/nai_launcher/probe --wait
./scripts/run.ps1 api GET /api/backends
```

不提供任意 MCP 方法、远程 endpoint、token 输入或“信任当前哈希”的 HTTP 接口。凭据仅使用运行时内存；诊断不会改变项目数据库、来源状态、图片或标注。
