## 矩阵与交互

采样预览、任务报告和人工复验结果预览新增矩阵。数据来自冻结 request 中的主维度/取值及后端报告中的 cell_targets/cell_counts；不从当前词典或可见样例推测配额。每格显示目标、实际、缺口（或超额），满足用 success 语义令牌，缺口用 warning，保留文字信息；不只靠颜色。报告没有目标键的格子明确显示“已排除”，不能点击，不当成目标 0。纯随机模式展示一个明确的随机池，不构造无意义的二维坐标。

二维可交换行列；三维任选两维作行列，剩余一维筛选。cell_id 始终按冻结主维度顺序生成规范 JSON 数组，不使用容易冲突的拼接串。中文、引号、逗号、特殊对象键不改变身份。每页最多 10 行×10 列，行列分别翻页，最多 100 个格子按钮；大方案仍保留全部格子，翻页只改变显示范围。

可点击格子，或用 Tab 聚焦后 Enter/空格打开明细。更换维度/筛选会收起旧切片明细。采样配置改变时沿用既有预览失效规则，矩阵和明细一同隐藏，不自动重采样或放宽约束。任务 revision 变化时重置格子选择，旧页游标不可用于新结果。

明细只显示与实际数量对应的已选集合，不混入待检查、失败、未处理或未入选合格候选。每页 50 条，可前后翻页，显示完整标签、描述、图幅、评级与是否已验证；不把前 100 条样例当成全集。表中的序号对应选中结果顺序，不表示精修候选原始 index。人工复验提交前的矩阵只展示预计计数；保存后可从任务报告查看完整明细。

## 后端与一致性

新增投影模块 `prompt_production/matrix.py`。采样预览在同次 sample 返回后冻结完整格子目标与已选条目，不存密钥、当前词典引用或可执行对象。原 preview_digest 继续绑定任务创建所需的输入快照，新 coverage_view 的 digest 独立绑定全部明细内容。读取明细不重新 freeze、采样、调用模型或写项目文件。

预览明细保留最多 3 次，总编码数据不超过 64 MiB；写入时淘汰最旧视图，15 分钟后失效，读写时清理过期项。这里的字节上限指编码后的数据量，不是 Python 进程总内存承诺。单份超限时不保留明细，返回明确原因；覆盖报告、前 100 条样例及原任务创建仍可用，不返回伪装成完整列表的截断明细。可主动释放视图；释放可重复，错误摘要不会释放别人的视图。视图仅存在当前进程内，重启后不可恢复，但持久任务报告仍可读取。

任务明细只读当前已保存 result.outcomes，通过 expected_revision 绑定请求；未有结果返回明确错误，版本变化返回冲突，已清理任务返回 410。已有词典或覆盖方案变化不会改变任务明细。人工复验改变最终集合后，新 revision 的数量与明细一起可见，旧 revision 不能继续翻页。仍使用原有任务文件完整性校验与删除屏障。

分页游标绑定资源身份（预览或任务）、预览摘要/任务版本和规范格子，再绑定完整列表摘要；跨格子、跨预览、跨版本串用拒绝。分页大小沿用现有 API 上限 1000，UI 使用 50。查询字段严格检查缺省、重复、未知字段及大小，沿用会话鉴权与 Origin 边界。

| 方法与路径 | 行为 |
|---|---|
| POST `/api/prompt-production/coverage/preview` | 原报告增加 matrix、coverage_view（可空）及 coverage_view_reason；不改变任务创建合同 |
| GET `/api/prompt-production/coverage/previews/{id}/entries` | digest、cell、limit/cursor；只读冻结明细，过期/已释放/已淘汰为 410 |
| DELETE `/api/prompt-production/coverage/previews/{id}` | digest；释放内存明细，报告和冻结任务不变 |
| GET `/api/prompt-production/tasks/{id}/coverage/entries` | expected_revision、cell、limit/cursor；只读指定版本的最终已选条目 |

任务 coverage 报告与人工复验 coverage 预览增加 matrix 展示元数据，计算时不落入原 result 文件。能力增加 coverage_matrix_details。OpenAPI 与前端类型已重新生成。
