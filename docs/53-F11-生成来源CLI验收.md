## 本轮范围

接续 0.45.0 提示词任务 CLI，实现 F11 §9 的生成来源命令：capabilities、create、preview、run、reconcile、list、status、items、pause/resume/cancel、cost-state、confirm-cost、set-cost-policy。均附着当前用户的运行实例，通过既有 HTTP 服务执行，不直接写 SQLite、不自行调用生成后端。

create 当前只支持 --type nai；list/status/items 可以查看当前项目的两类来源，其余来源控制限定 nai。导入来源的创建、控制、路径重新授权和失败项 retry-item 留待后续阶段；旧本地 import/export 命令保持原有行为。

run 使用已就绪产品提示词任务的交接预览。这是将 F11 原先的 --seeds FILE 入口细化为已实现的 F04/F13 HTTP 合同：先明确任务编号与修订号，服务冻结内容，审核预览后启动。CLI 不新增任意 seeds 写入接口；项目 source_items 仍只保存 seq/prompt/aspect 等内容，不保存产品词典或提示词任务引用。

本轮未接入生产 Launcher 适配器。正式运行时 capabilities.generation 仍为 false，预览保留 generation:adapter_unavailable 等阻断原因，不能用 CLI 绕过。状态机和派发测试仅注入本地 FakeDriver，真实进程验证草稿、费用策略持久化、无适配器门槛和实例重启。

## 创建和交接

先保持 `./scripts/run.ps1 serve --no-browser` 运行，用 `project open` 打开项目、`project status` 获取当前 project_id。每个带数字来源编号的命令要求明确 --project-id；list 可省略，查看当前项目。capabilities 为产品级查询，不要求项目。没有自动拉起服务、自动切换项目、独立容器或 --project 路径参数。

```powershell
./scripts/run.ps1 source capabilities
./scripts/run.ps1 project status
./scripts/run.ps1 source create --type nai --spec .\draft.json --project-id <project_id>
./scripts/run.ps1 source list --limit 20
./scripts/run.ps1 source status <source_id> --project-id <project_id>
./scripts/run.ps1 source items <source_id> --project-id <project_id> --limit 50
```

draft.json 为严格 Draft 对象。以下为结构示例；模型、采样器、effort 和调度名称需根据未来已验收适配器的契约选择，示例不宣称当前可连接真实 Launcher：

```json
{
  "name": "本地生成来源",
  "target_count": 10,
  "cost_policy": "ask",
  "style_prompt": "geometric style",
  "negative_prompt": "unwanted objects",
  "config": {
    "schema_version": 1,
    "backend": "nai_launcher",
    "default_aspect": "portrait",
    "sizes": {
      "landscape": {"width": 768, "height": 512},
      "portrait": {"width": 512, "height": 768},
      "square": {"width": 640, "height": 640}
    },
    "profile": {
      "model": "nai-diffusion-5-full",
      "effort": "high",
      "sampler": "<契约支持的采样器>",
      "steps": 17,
      "scale": 4.5,
      "cfg_rescale": 0,
      "noise_schedule": "<契约支持的调度器>",
      "uc_preset": null,
      "quality_toggle": false,
      "smea": false,
      "smea_dyn": false,
      "variety_plus": false,
      "decrisp": false
    }
  }
}
```

未指定 cost_policy 时默认 ask。cost_policy=allow 的草稿必须同时传 --confirm-allow；其它策略不接受此开关。未知字段、秘密/外部位置配置字段、错误类型或尺寸在附着前拒绝；错误输出不回显原文件或校验异常内容。文件严格 UTF-8（可带 BOM），上限 16 MiB，拒绝重复键、非有限数字及过大输入。

通过前阶段 prompt 命令生成 ready 任务，检查 revision，任务 seeds 数量必须与 target_count 一致。交接预览不派发生成、不新增 source_items：

```powershell
$lines = ./scripts/run.ps1 source preview <source_id> --project-id <project_id> --task-id <task_id> --expected-task-revision <revision>
$previewExit = $LASTEXITCODE
if ($previewExit -notin @(0, 6)) { throw '预览失败，请查看返回错误' }
$text = $lines -join [Environment]::NewLine
[IO.File]::WriteAllText((Join-Path (Get-Location) 'source-plan.json'), $text, [Text.UTF8Encoding]::new($false))
$preview = $text | ConvertFrom-Json
$preview.plan.preview | ConvertTo-Json -Depth 30
$preview.confirmation_digest
```

审核 can_start、blockers、trigger_validation、cost_policy、examples、宽高分布与内容摘要。退出 6 表示预览被阻断，不能继续 run。成功预览的格式化输出同样检查 16 MiB 上限，确保保存后可读；超大返回 source:plan_too_large。

```powershell
./scripts/run.ps1 source run --preview .\source-plan.json --confirm-digest <confirmation_digest> --detach
./scripts/run.ps1 source status <source_id> --project-id <project_id> --wait
./scripts/run.ps1 source pause <source_id> --project-id <project_id>
./scripts/run.ps1 source resume <source_id> --project-id <project_id> --detach
./scripts/run.ps1 source cancel <source_id> --project-id <project_id>
```

run/resume/confirm-cost 默认等待到非 running；--detach 立即返回当前服务响应。HTTP start 是 200，CLI 保留来源的实际 status、reconciled 和 dispatched，不合成“已完成”。status 默认读一次，加 --wait 等到非 running；暂停的 nai 来源额外返回 cost_state。草稿或暂停的一次状态查询返回 7；查询列表、条目、费用状态返回 0 只表示查询成功。

暂停来源需明确 resume；再次执行旧 run 计划只核对冻结投影，不自动恢复、增加条目、重新解析任务或再次派发。服务返回 dispatched=true 表示已交给驱动处理，不能作为图片成功或费用结算凭证。所有等待中 Ctrl+C 退出 130，只结束客户端；来源身份与最后写请求保留在 cli 对象，后台工作不被隐式取消。

## 计划、并发和恢复

计划 schema_version=1 包含 instance_id、project_id、source_id、idempotency_key、HandoffStart 请求体及完整预览。SHA-256 confirmation_digest 覆盖计划；run 验证对象结构、字段一致性和确认摘要，再附着同一实例和项目。摘要不是服务签名或价格保证。预览版本、任务修订、后端能力、触发词、内容投影的最终校验仍由服务执行；CLI 不自动刷新过期预览、不自动换版本重试。

preview 默认 GET 来源后捕获 version，也可显式 --if-match。pause/resume/cancel/confirm-cost/set-cost-policy 同样默认读取一次来源版本；冲突原样返回。明确重放时必须同时提供原 --instance-id、--if-match、--idempotency-key，GET 仅检查来源类型，提交仍使用原版本。服务已有目标状态 no-op 及会话幂等缓存语义保持不变：重放返回历史请求结果不代表最新状态，必要时另行 status。list/items 每次只读一页，不自动合并多个时点；cursor 绑定服务原有分页范围。

POST/PATCH 发出前记录 cli.request（method/path/body/idempotency_key/if_match），网络超时、重定向或无效成功响应视为结果未知，退出 7，不自动再发请求。PATCH 现使用与 POST 相同的传输收据、If-Match 和未知结果处理。create 的未知结果没有预分配持久来源编号；只可在同一实例以原 spec、project_id 和请求键明确重放，不能跨重启假定创建幂等：

```powershell
./scripts/run.ps1 source create --type nai --spec .\draft.json --project-id <original_project_id> --instance-id <original_instance_id> --idempotency-key <original_key>
./scripts/run.ps1 source pause <source_id> --project-id <project_id> --instance-id <original_instance_id> --if-match <original_version> --idempotency-key <original_key>
```

run 的持久核对依据是服务保存的 source_digest/seeds_digest/count，不能只依赖会话请求键。网络中断后可用原计划明确核对：

```powershell
./scripts/run.ps1 source reconcile --preview .\source-plan.json --confirm-digest <confirmation_digest> --project-id <current_project_id>
```

reconcile 只调用现有 reconcile-start 内容投影核对，不派发、不恢复、不确认费用，也不写来源。它允许在重启后明确提供新 project_id，在新实例核对原来源编号的内容投影；不是项目全局身份/历史证明。请明确重新打开原项目后使用。已冻结且投影一致返回 reconciled=true；未启动返回 false 和退出 7；不一致返回冲突。旧 run 计划仍拒绝跨实例执行；确认暂停工作可继续后，再用新项目句柄明确 resume。

## 费用确认

```powershell
./scripts/run.ps1 source cost-state <source_id> --project-id <project_id>
./scripts/run.ps1 source confirm-cost <source_id> --project-id <project_id> --cycle-id <current_cycle_id> --detach
./scripts/run.ps1 source set-cost-policy <source_id> --project-id <project_id> --policy deny
./scripts/run.ps1 source set-cost-policy <source_id> --project-id <project_id> --policy ask
./scripts/run.ps1 source set-cost-policy <source_id> --project-id <project_id> --policy allow --confirm-allow
```

cycle_id 沿用 F01/F04 的 **32 位小写十六进制**，并非带连字符 UUID。confirm-cost 必须明确传入已审核周期，不从 GET 自动选择或替换周期；服务仍校验当前来源版本、ask 暂停、待确认估算、驱动与设置恢复状态。deny 不能被 confirm-cost 覆盖；过期周期拒绝。确认本身会恢复该来源，--detach 只控制客户端是否等待。

非交互运行遇非零费用 ask 时暂停并退出 7，不自动同意、修改策略或发送该项。普通 pause/resume 会清掉旧 ack，新周期需要再次明确确认。设置策略为 allow 必须额外 --confirm-allow；set-cost-policy 仅修改策略，不自动恢复暂停来源。已有费用记录只是本地估算/派发证据，CLI 不宣称实际扣费、账户余额或零估算必然免费。

stdout 默认一个 JSON，--json 可省略；等待和中断提示写 stderr。结果含 cli 身份和收据，不输出 Bearer token、原始异常或 spec 绝对路径；正常来源提示词、配置和条目内容按现有 API 返回。

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 查询/创建/策略更新成功；控制目标已达到；--detach 返回 running；done 且无 failed；reconcile 投影一致 |
| 2 | 参数、spec、计划或格式错误/过大；不支持的来源控制类型 |
| 3 | 无运行实例或认证不可用 |
| 4 | 实例、项目、版本、状态、费用周期或投影冲突；阻断计划；过期预览 |
| 5 | 依赖/I/O/读取失败或无效查询响应 |
| 6 | 预览 can_start=false；来源 done 但有 failed 条目 |
| 7 | draft/running/paused/canceled 一次状态查询；等待结束但未完成；未冻结的核对；请求结果未知 |
| 130 | 客户端中断，后台任务继续 |
