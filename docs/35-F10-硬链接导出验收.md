# F10 可选硬链接导出实现与验收

日期：2026-10-26；版本：0.28.0。仅本地开发、打包和验收；未初始化、提交或上传 Git。

## 范围与设计同步

落实 F09–F10 §10、C16、Q06、T23/T28；同步 05 §10.2 的图片输出合同。默认仍为 copy，方案可显式选择 hardlink；仅同卷、目标不存在且 pipeline=[] 可执行。标签排序与 caption 逻辑保持，非空后处理链、prompt_pyramid 仍拒绝执行。不引入新数据库表或迁移。

硬链接共享同一文件内容：外部工具改写导出图会影响项目原图，后续其它导出硬链接也会看见改变。删除一个链接仅移除该目录项。此能力适合只读训练读取，不提供图片内容隔离；输出 SHA-256 是导出时记录，不保证日后不变。TXT 和 JSON 独立创建。

## 执行与一致性

1. 预览冻结现有方案、选图、标签与项目数据，返回 output_config.image_mode、共享内容提示及 hardlink_ack_digest（绑定 plan_digest）。预览不创建链接或导出目录。
2. HTTP 执行必须提供匹配摘要；缺失返回422，错配/复制模式携带旧摘要返回409，拒绝发生在创建后台导出记录之前。后台重新计算计划，图片审核/标注/方案变化会在创建目录前拒绝。CLI `--acknowledge-hardlink` 明确确认后读取计划并绑定执行；不默认启用、不用于复制方案。
3. exclusive os.link 创建图片链接，先检查卷号；跨卷、不支持、权限/空间错误均不回退复制。链接后以打开文件句柄与源/目标路径核对文件身份、大小、mtime 和 SHA-256。
4. 图片、caption 和可选 JSON 组成逐图暂存文件组。某图写入失败清理本次文件组；失败原因进入报告。磁盘满等整体错误以及取消不发布正式目录。其它图正常完成时可发布包含逐图失败的完整报告，不能将失败图计作成功。
5. 全部文件组完成后，在发布前再次验证成功图片的源/目标文件身份与哈希，并检查取消。即使外部把原路径替换为字节相同的新文件，也因已不再是同一文件而拒绝发布。最后整体 rename 为新的版本目录，旧目录不覆盖。
6. 捕获到中断时尽力移除明确记录的本次临时图片链接，保留 interrupted 收据；操作系统阻止清理时记录 hardlink_cleanup_pending=true。强制终止进程不能保证清理，历史中断目录可能仍含共享链接。原图路径从不列入清理目标。

项目内文件操作沿用现有串行锁。无法阻止项目外程序在最终校验后修改共享文件；界面和报告明确此限制，不宣称硬链接是不可变快照。SHA 或身份不符不会自动更新项目数据库。

## HTTP、页面与报告

- `/api/exchange/capabilities` 声明 copy/hardlink，并标记 hardlink_requires_confirmation=true；结构合法的硬链接方案可执行，非空链仍不可执行。
- “导入导出方案 → 图片导出方式”默认复制，选择硬链接时说明共享风险、同卷限制和失败策略。
- “导出数据集”显示所选方式；生成预览后必须勾选本次共享风险确认。重新预览自动清除勾选；触发词重合确认仍独立检查。
- `POST /exports` 增加可空 `hardlink_ack_digest`。报告保存实际 output_config.image_mode、确认摘要与 warnings；中断收据保存 image_mode。会话恢复从正式报告/中断收据恢复方式，旧报告缺省复制。
- 导出记录和报告均显示硬链接共享提示；中断或取消记录提示临时目录可能残留共享图片。跨卷/不支持硬链接的报告原因以中文解释。
- 无任何真实业务图片被用于本轮写入验证；所有共享写入演示使用临时测试图。
