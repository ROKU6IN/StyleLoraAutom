版本：0.20.0；日期：2026-10-26。依据 [F06/F07 设计](F06-F07-提示词生产设计.md) §5–8 的部分结果导出、任务保留与清理合同继续本地开发。未修改项目数据库 schema，未初始化、提交或上传 Git。

## 任务存储与清理

“提示词生产”新增任务存储面板，单独展示任务快照/结果文件和最小去重记录的字节数。数值为文件逻辑长度，不宣称等于磁盘分配块或实际可用空间。列表每页 50 行，选择上限 200 个，可选择前 200 个符合条件的任务；选择跨分页保留。

运行中、等待执行、已暂停/取消但后台尚未退出，以及存在已返回但未成功落盘结果的任务不能清理。用户需先停止任务并等待排空，必要时先恢复结果保存。已停止任务须明确确认结果保留责任，再按住按钮 1 秒执行；没有 TTL 自动删除。损坏任务只显示不可用和占用，不能借清理入口静默删除证据。

批量清理先核对所有所选 UUID、revision、任务状态和文件内容；任一预检冲突不写文件。随后逐任务执行，不声明跨文件全批原子性：

1. 在产品目录 `prompt_tombstones/<uuid>.json` 原子写入最小删除凭据，包括任务 ID、创建请求键/摘要、旧 revision、原文件内容摘要/长度和清理请求键/摘要。无词典快照、提示词、模型绑定、项目或来源字段。
2. 删除屏障生效后，再检查并移除同 UUID 的原 `prompt_tasks` 文件。路径限定在受管理产品分组，沿用 UUID、链接与内容完整性校验；没有递归删除或路径型 HTTP 入参。
3. 清理成功时释放本任务的导出预览和运行索引。创建请求键保留在去重记录中；旧任务 ID 返回 410，旧创建键不能换 ID 重启。重启先读取删除凭据，即便崩溃发生在凭据提交与原文件移除之间，也不会重新派发模型任务。

中途磁盘失败返回 `prompt:cleanup_incomplete`/unknown，包含已完成 ID；界面保持原选择、revision 和请求键，不自动重试。用户可核对后继续；跨重启读取凭据完成剩余清理。若原文件与记录摘要不同则保留文件并报冲突。已全部清理的重复请求仅核对记录，不重新创建文件或派发工作。清理待完成的文件也可在存储面板重新选择继续。

保留原 2048 个活动任务文件上限；清理释放这些名额。最小删除凭据另限 100000 个，不自动过期以避免旧请求复活；达到上限时清理报错并保留待清理文件。损坏凭据不被当作“不存在”。清理不修改词典，也不修改 project.db。已锁定来源完整 items/config 的核对与恢复不依赖生产任务文件。

## 部分合格结果导出

任务详情新增预览与下载，支持 JSON、CSV、TXT，文件最多 10 MiB。仅接受停止且后台已排空的持久结果；不调用 LLM、不重新抽样、不读取今天的词典或重写任务状态。旧任务没有记录的候选不会为了补足导出而重新计算，所以部分旧任务可能没有可导出的条目。

扫描完整持久 outcomes，不受前端当前 50 条分页限制。只接纳 ok/skipped 条目，按冻结输入/标签库/内容规则重验，检查冻结围栏，并以规范标签集合去重。失败、待审核、围栏排除和不合规条目排除并报告计数；不把输入原值冒充失败项的成功结果。相同标签但不同描述/图幅不能绕过批内去重。

JSON 使用独立 `kind=prompt_task_results` 格式，包含完整结构化 rows、原任务状态/ready、目标数量、原任务覆盖报告、排除统计以及 `usable_for_start=false`。每行保留标签顺序、NL、aspect、rating、评级 verified、精修状态和是否进入最终 seeds。CSV 保留结构化条目和就绪/目标摘要，但不包含完整任务/覆盖报告；TXT 仅内容行，图幅、评级、结构等有损，必须明确勾选确认。

结果文件与词典交换格式、启动用 FrozenSeeds 均有区别。本阶段没有新增结果文件重新导入功能；已有词典追加仍使用任务合格条目的预览/追加流程。导出数可以小于目标，精修后未被覆盖求解选中的合格候选也可导出；原任务覆盖报告不代表导出集合重新通过覆盖。未就绪任务始终不能通过既有 `/seeds` 或源交接启动。

预览最多返回 20 条样例，私有预览冻结完整文件；下载校验任务 ID、revision、预览摘要和 TXT 确认。任务变化或清理后旧预览失效，浏览器也立即隐藏失效预览。下载是本地浏览器文件，不写入项目、不触发外部服务调用。

## HTTP

| 接口（前缀 `/api/prompt-production`） | 用途 |
|---|---|
| `GET /task-storage` | 简要任务清单、字节占用、清理资格及凭据总量，无模板/原始模型回复 |
| `POST /task-cleanup` | tasks: task_id + expected_revision，最多 200 个；必需 Idempotency-Key；逐任务持久删除屏障 |
| `POST /tasks/{id}/results-preview` | expected_revision、format → 条数、损失字段、排除计数、20 条样例及预览身份 |
| `POST /tasks/{id}/results-export` | preview_id、digest、acknowledge_lossy → filename/media_type/content |

既有任务查询新增 storage_bytes、can_cleanup、cleanup_reason、can_export_results；能力端点声明本阶段功能。请求沿用本地认证、Origin 校验、严格 DTO 和脱敏错误。新增 `prompt.task_deleted` 摘要事件仅含任务 ID、revision 和 ready，不含内容或凭据。清理完成后当前任务详情收起，缓存和任务列表刷新。
