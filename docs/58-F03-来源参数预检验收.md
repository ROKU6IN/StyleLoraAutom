## 已实现

`generation/launcher_check.py` 在保存来源和新读取的 Launcher 设置间进行比较：

- 固定比较 model、effort、sampler、steps、scale、cfg_rescale、noise_schedule、uc_preset、quality_toggle、smea、smea_dyn、variety_plus、decrisp。每项返回来源值、明确映射后的期望值、观察值、是否一致、是否被当前模型固定。浮点值采用原值比较，不自动改参数或套默认值。
- 本地 None 只在比较时映射为 Launcher 整数 3。V5 Full 两个已核对模型标识按 high/medium 映射；其它模型和别名不猜测、不自动替换。模型与 Effort 不在 Launcher 返回的列表内时单独提示。
- 来源有自定义负面词且当前 `locked_by_effort` 含 negative_prompt 时提示冲突；不输出负面词内容。存在进行中的生成或等待队列时提示当前活动，历史完成计数和 completed 状态不冒充具体 attempt 已结清。
- 来源的横/竖/方尺寸与默认方向单独显示，不拿当前页面宽高判等，因为尺寸属于每次请求参数；具体模型的尺寸支持仍标为未验证。
- 所有结果固定 `generation_enabled=false`。即使所有可读取字段一致，也列出有效生成参数、继承参考图、批量大小、尺寸支持、原子设置更新、持久 attempt 结果这六类未验证条件。不锁定来源，不生成费用授权或设置恢复记录。
- 每次新检查创建独立 MCP 会话，调用既有两个已审核的只读工具。采用与全局诊断相同的版本/schema、响应过滤、时限与重连保护；不复用旧 Launcher 缓存，也不覆盖全局 Launcher 页面诊断。

服务端缓存与后台任务绑定当前 project_id、source_id、source_version。入队前核对 If-Match；实际开始前和发布结果前再检查来源版本。排队期间已编辑则不联系 Launcher；读取期间编辑则丢弃结果，任务失败为 `launcher_check:source_changed`。进行中的同来源同版本检查复用原任务；不同版本不能混用，返回 `launcher_check:busy`。

GET 只读取缓存与当前来源版本，后续编辑使历史结果 `stale=true`；重新进入页面不会自动连接 Launcher。失败检查替换旧成功结果为 unavailable，取消或版本冲突保留原结果。结果是两个相邻时刻的读取快照，不代表持续在线或原子生成状态。项目关闭会取消该项目检查，等待任务释放项目句柄后清空缓存；关闭后旧任务和项目 API 沿用 410 失效语义。

## HTTP 与工作台

P 为 `/api/projects/{project_id}/sources/{source_id}`：

| 方法与路径 | 行为 |
| --- | --- |
| `GET P/launcher-check` | 返回 source_version、operation_id、result、stale；不联网。 |
| `POST P/launcher-check` | 严格空 JSON、无查询参数、必需 If-Match 与 Idempotency-Key；返回 202 后台 operation。 |
| `GET /api/operations/{id}` | 沿用任务查询；checked/unavailable 是诊断结果状态，任务正常完成为 done。 |
| `POST /api/operations/{id}/cancel` | 沿用任务版本保护，取消此次读取，保留上次缓存。 |

POST 的幂等记录绑定原 If-Match。相同请求键与原版本重放返回原任务，不因来源变化再次连接；同键换版本返回 `idempotency:key_conflict`。新键旧版本正常返回版本冲突。导入来源、其它项目、未知来源不允许进入生成来源预检；来源类型和版本检查均在连接之前完成。

工作台“来源与导入”打开已保存的生成来源后显示“Launcher 参数预检”：

1. 先保存草稿，未保存更改时禁止发起检查。
2. 点击“读取并比较 Launcher 参数”，显式开始后台读取；不需要提供 endpoint/token。
3. 查看参数对照表、固定项、负面词冲突和来源尺寸。对于 UC None 和 V5 Effort，表格展示映射前后值，便于核对。
4. 可以取消正在进行的检查；重新加载页面仍能查询此实例中该来源的任务。来源版本变化后旧结果标为历史结果，不显示为当前一致。
5. 页面始终说明生成尚未开放；没有“应用 Launcher 参数”“修改页面”或“开始生成”的新增动作。

返回内容不包括提示词、路径、令牌、上游原始错误或图像引用。来源摘要仅为内容摘要，不能用来伪造启动、费用或恢复授权。
