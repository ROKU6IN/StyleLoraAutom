# F06/F07 生成源交接验收

版本：0.19.0；日期：2026-10-26。依据 [F06/F07](F06-F07-提示词生产设计.md) §8 和 [F02–F05](F02-F05-生成后端设计.md) §4 实现生成源交接桥接。仅本地开发、测试和构建，没有初始化、提交或上传 Git。

## 交付与边界

生产界面现在可创建和编辑 NAI 源草稿、选择就绪的提示词任务并预览交接。草稿必须显式填写完整 profile、三组实际像素、默认图幅、目标数量、画风、负面词与费用策略。默认模型为 `nai-diffusion-5-full`；小/大尺寸来自设计。`quality_toggle=false`、`uc_preset=null` 固定，sampler、steps、effort、scale 等不推测后端有效默认值。JSON 表单暂代动态能力表单；本地结构校验不表示 Launcher 支持这些参数。

服务启动桥接已实现完整 seeds 原子落库与锁源、提交未知核对、暂停/恢复/取消路由；测试注入内部 `GenerationDriver` 调度夹具验证合同。生产未提供 driver，现有 `REVIEWED_CONTRACTS` 仍为空，未新增信任入口。即使能保存草稿，真实启动仍返回 `generation:adapter_unavailable`，保持空 source_items 和未锁定草稿。没有请求真实 Launcher、LLM，也没有 Anlas 花费。

## 交接和恢复

- 预览调用 `PromptProduction.seeds(task_id, expected_revision)`，仅接受 ready 的完整冻结结果。检查目标 N 相等、任务 revision 和源 If-Match；不重新抽样、不精修，也不写项目条目。返回完整摘要、图幅计数和最多 100 条样例，私有预览保存所有条目。
- 每项只交接 `seq/prompt/aspect`，序号连续 1..N。item.aspect 缺失仍以 null 落库；构造请求时采用源默认图幅及对应实际像素。正向为画风 + 内容，负面为源负面词；count=1、operation=generate、characters=[]。不加入触发词。
- 项目仅保存源参数和 F01 items，不存生产任务 ID、词典引用、采样种子、rating 或精修角色信息，不创建 jobs/images。没有修改项目 schema。
- 启动前核对源版本、预览绑定、完整配置摘要、审核能力 schema 和触发词报告。能力 schema 禁止远程引用；effort 锁定负面词时不能携带自定义负面词。F22 使用完整本地规范 tag/alias 索引；索引不完整拒绝启动。画风包含规范化触发词时拒绝，连续空白与下划线等价处理。writer 内再次检查源及触发词摘要，防止等待期间漂移。
- 整份列表只调用一次 `commands.start_source`，在一笔事务中写入并锁定。提交后才调度；并发重复启动通过锁和完整投影核对只派发一次。没有逐页追加、边生成边填充或只检查首条。
- 写入异常先读取数据库的完整锁定配置及全部 `(seq,prompt,aspect)`。未提交则保持原草稿；已提交且完全一致则暂停并返回 reconciled，不派发；不一致返回冲突。调度异常也暂停保留已锁定输入，不能静默再派发。
- 已锁定源的重复启动先做投影核对，不依赖原预览、任务、词典或生成后端。重启后新会话也可核对。恢复只读取锁定源/items，经能力门禁与在途检查后派发；存在未核对 sent 项时 F01 拒绝恢复。相同 running 状态的重复 resume 不再次派发。
- 创建草稿复用现有**会话级** Idempotency-Key；提交后回执丢失可用本次分配的 source_id 核对。它不是跨进程创建凭据：跨会话未知创建应先查看来源列表，不能直接自动重建。启动去重则由数据库完整投影提供，不依赖会话缓存。

预览有效期和资源清理由既有 PreviewStore 管理。生产页面在适配未开放时禁用启动；编辑草稿立即隐藏旧预览，保存冲突保留本地输入，离开时提示未保存草稿。有可用适配时还需用户明确确认锁源与费用策略。启动响应未知时浏览器只调用只读核对端点，不自动再次启动。预估 Anlas 为 null，不能解释为零费用。

## HTTP

| 接口 | 用途 |
|---|---|
| `GET /api/generation/capabilities` | 本地能力、尺寸模板、参数 schema；当前 generation=false |
| `POST /api/projects/{pid}/sources` | 创建 NAI 草稿，201，会话幂等键 |
| `PUT /api/projects/{pid}/sources/{sid}` | If-Match 更新未锁定 draft |
| `POST /api/projects/{pid}/sources/{sid}/handoff-preview` | task_id、expected_task_revision、If-Match → 完整交接预览 |
| `POST /api/projects/{pid}/sources/{sid}/start` | preview_id/digest、source_digest/seeds_digest/count、If-Match 和请求键 → 原子启动/既有结果核对 |
| `POST /api/projects/{pid}/sources/{sid}/reconcile-start` | source_digest/seeds_digest/count → 只读核对，不依赖预览和生产任务 |
| 既有 `/sources/{sid}/control` | 根据 import/nai 类型分别执行控制；draft NAI 不走导入恢复 |

沿用本地认证、Origin、项目租约、严格请求校验和脱敏错误；无 URL/凭据写入项目的新增入口。事件仅包含源 ID、状态、计数和版本。
