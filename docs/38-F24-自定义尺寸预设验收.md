# F24 自定义尺寸预设验收

日期：2026-10-26；版本：0.31.0。依据 `05-项目结构与数据模型.md` §4.5、F02–F05 §4、F11–F14 A023–A027、F14 §4.3。本轮仅本地开发、测试、打包，未初始化、提交或上传 Git。

## 使用入口与尺寸合同

侧栏“尺寸预设”（`#/settings/presets`）可新建、复制、修改和删除自定义预设。每份预设包含名称及横/竖/方三组实际像素。内置预设只读，可复制后编辑；默认仍为小尺寸。

| 预设 | 横向 | 竖向 | 方形 |
|---|---|---|---|
| 小（默认） | 768×512 | 512×768 | 640×640 |
| 大 | 1536×1024 | 1024×1536 | 1472×1472 |

名称去除两端空白后须非空，最多 200 字符，禁止控制字符。宽高严格为 64–16384 的整数且为 64 倍数，拒绝字符串、布尔、浮点、缺项与额外图幅，不自动取整。横向须宽大于高，竖向须高大于宽，方形须宽高相等；与生成源配置共用验证函数。预设有效不代表具体模型支持该尺寸，真实后端仍须按能力检查。

“来源与导入”的“填入尺寸预设”显示各组实际尺寸。选中后重新读取该预设，列表版本变化时刷新列表并要求重新选择，保持来源草稿不变；删除的预设报不存在。校验成功仅复制三组像素到当前草稿，并清除旧启动预览/确认，需点击“保存生成源草稿”。来源不存预设 ID、名称或外键。以后修改或删除预设不影响已有草稿或已锁定来源，逐项请求仍按 source item 的 aspect 选择已保存像素。

## 持久配置与 API

默认文件 `%APPDATA%/StyleLoraAutom/generation_presets.json`，按产品复用，无项目数据库迁移。使用 `serve --product-dir <目录>` 时配置在指定目录的 `llm/generation_presets.json`；测试运行时使用隔离目录或内存。仅读取内置预设不会创建文件。

文件包含 `content` 与内容 SHA-256 `digest`；content 有 schema_version、全局 revision 及按 UUID 索引的自定义预设。每项有自己的 revision。内置 UUID 由固定命名空间与键生成，不能被文件覆盖。最多 2048 份自定义预设、文件最多 8 MiB；名称允许重复，以 UUID 区分。读写校验完整信封、严格字段/类型、编号和版本，损坏文件报错，不重置或覆盖。路径拒绝符号链接/重解析点；写入沿用同目录临时文件、flush/fsync 和原子替换，进程内锁串行化修改。替换后异常会读取完整信封核对成功结果；不能证明提交结果时返回未知状态。生产进程沿用产品单实例锁。

| 方法与路径 | 行为 |
|---|---|
| GET `/api/presets` | 默认每页 50，最多 1000，页面每批请求 200；内置在前，自定义按 UUID 稳定排序。返回默认预设 ID，游标绑定清单摘要，清单变化报 page:stale |
| GET `/api/presets/{id}` | 完整像素、内置标记、修订、version/ETag |
| POST `/api/presets` | name/sizes 创建自定义预设，201；请求须有 Idempotency-Key |
| PUT `/api/presets/{id}` | name/sizes 更新，须 Idempotency-Key 与 If-Match；相同内容不增加修订 |
| DELETE `/api/presets/{id}` | 空请求体，须 Idempotency-Key 与 If-Match；成功 204，仅从配置移除该项 |

内置修改/删除 409 preset:builtin_locked；不存在 404 preset:not_found；缺版本 428、旧版本 409，非法 DTO 422 schema:invalid。文件/数量限制 413；损坏配置、读取错误和无法核对的写失败 503。API 沿用会话鉴权、同源检查、统一错误结构与请求键冲突检查。成功变更发 presets.changed，前端仅刷新清单，不覆盖正在编辑的草稿。生成能力增加 presets_endpoint/default_preset_id，兼容保留旧的内置 size_presets 字段。

请求去重沿用现有进程内机制：同一会话用同一键和载荷核对丢失回包，不重复创建或删除；同一键换载荷拒绝。配置和资源版本跨重启保留，但没有跨重启请求凭据库。若未知结果后服务已重启，先查看清单核对，再决定新的创建操作，不能宣称跨重启重试必定去重。

## 页面保护

管理页有六项整数输入和前置校验。新建/切换/重载/离页沿用草稿保存或放弃保护；保存失败、回包丢失、版本冲突均保留表单。相同草稿在当前页面重试使用同一请求键。内置内容不可编辑或删除，可复制成自定义草稿。已有自定义预设未保存的草稿须先处理，之后才能删除。

删除弹窗显示名称、编号、修订及六个像素值，须勾选并按住确认，提交携带已展示的版本。冲突保留弹窗，不删除新版本；未知回包可在同一弹窗用同一键核对。删除只影响后续选用，不触碰来源或图片。
